# Hyper Reply

Omnichannel customer support hub: email, SMS, phone, WhatsApp and chat.

## Features

- Unified conversations
- Client management
- Statistics

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/hyper-reply-now.git
cd hyper-reply-now
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
